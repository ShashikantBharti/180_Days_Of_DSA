## 💬 Interview Q&A
### Q1: Linked vs Indexed Allocation?
**Ans:** Linked: Each block has a pointer to the next (no external frag, slow access). Indexed: All pointers are in one block (fast access, supports large files).

### Q2: What is an inode in Linux?
**Ans:** A data structure that stores all information about a file except its name and actual data (metadata).
