## 💬 Interview Q&A
### Q1: What is a Process?
**Ans:** A program in execution. It includes code, data, stack, and heap.

### Q2: Explain the components of a PCB.
**Ans:** Process ID, State, Program Counter, CPU Registers, Memory management info, I/O status info.

### Q3: Describe the process state transition.
**Ans:** New -> Ready (admitted) -> Running (dispatch) -> Terminated (exit). Processes can go from Running to Waiting on I/O.
