## 💬 Interview Q&A
### Q1: What is an Operating System?
**Ans:** An OS is software that acts as an interface between user applications and computer hardware, managing resources like CPU, memory, and I/O.

### Q2: Explain Multiprogramming vs Multitasking.
**Ans:** Multiprogramming keeps multiple programs in memory to keep the CPU busy. Multitasking is a logical extension where CPU switches between tasks so rapidly that users can interact with each program.

### Q3: What is a Real-Time OS (RTOS)?
**Ans:** An OS intended for applications with strict timing constraints, where processing must be done within a specific time limit (e.g., flight control systems).

### Q4: What is the main purpose of an OS?
**Ans:** To provide a convenient environment for users, allocate resources efficiently, and manage hardware.
