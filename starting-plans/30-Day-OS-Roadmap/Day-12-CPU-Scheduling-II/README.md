## 💬 Interview Q&A
### Q1: How does Round Robin work?
**Ans:** Each process gets a small fixed unit of CPU time (quantum). If it doesn't finish, it goes back to the end of the ready queue.

### Q2: What happens if the time quantum is too small?
**Ans:** Context switch overhead becomes too high, slowing down the overall system.
