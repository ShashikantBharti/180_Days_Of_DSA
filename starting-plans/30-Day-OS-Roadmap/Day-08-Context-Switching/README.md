## 💬 Interview Q&A
### Q1: What is Context Switching?
**Ans:** The process of saving the state of the current process and loading the state of the next process when the CPU switches tasks.

### Q2: Why is Context Switching considered overhead?
**Ans:** Because the CPU does no 'useful work' (executing user code) while switching. It purely manages OS data structures.

### Q3: Define Turnaround Time.
**Ans:** Total time taken from process submission to completion (Completion Time - Arrival Time).
