## 💬 Interview Q&A
### Q1: Difference between Monolithic and Microkernel?
**Ans:** Monolithic kernels combine all services into one large kernel space (faster but crash-prone). Microkernels move non-essential services to user space, communicating via message passing (stable but slower).

### Q2: What are the advantages of a Microkernel?
**Ans:** Better stability and security, as a crash in one service doesn't crash the entire kernel. Easier to extend.

### Q3: What is a Hybrid Kernel?
**Ans:** Combines monolithic speed with microkernel structure (e.g., Windows NT, macOS kernel).
