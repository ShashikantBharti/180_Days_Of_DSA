## 💬 Interview Q&A
### Q1: What is a Thread?
**Ans:** A basic unit of CPU utilization, also called a lightweight process. Threads share the same code and data but have their own stack and PC.

### Q2:  ULT vs KLT?
**Ans:** ULTs are managed by user-space libraries (invisible to kernel). KLTs are managed directly by the OS (better for multi-processing).

### Q3: Why use threads instead of processes?
**Ans:** Faster context switching, less memory overhead, and easier communication since they share memory.
