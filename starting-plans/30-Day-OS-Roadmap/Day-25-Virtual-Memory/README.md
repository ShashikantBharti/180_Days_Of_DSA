## 💬 Interview Q&A
### Q1: What is a Page Fault?
**Ans:** An interrupt triggered when a process tries to access a page that is not currently mapped in physical memory.

### Q2: What is Belady's Anomaly?
**Ans:** A phenomenon where increasing the number of frames results in an increase in the number of page faults (occurs in FIFO).

### Q3: What is Thrashing?
**Ans:** A state where the system spends more time swapping pages in and out than executing instructions.
