## 💬 Interview Q&A
### Q1: What is the Memory Management Unit (MMU)?
**Ans:** Hardware device that maps virtual (logical) addresses used by programs to physical addresses in RAM.

### Q2: Compile Time vs Execution Time Binding?
**Ans:** Compile time: absolute addresses known at compile. Execution time: Binding delayed until process runs (allows relocation).
