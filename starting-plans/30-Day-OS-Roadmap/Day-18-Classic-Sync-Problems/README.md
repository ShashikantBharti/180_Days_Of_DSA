## 💬 Interview Q&A
### Q1: Explain the Dining Philosophers problem.
**Ans:** A classic sync problem involving resource contention and potential deadlock when N philosophers need 2 chopsticks to eat.

### Q2: What is the Bounded Buffer problem?
**Ans:** A problem where producers add items to a fixed-size buffer and consumers remove them. Requires sync to prevent overflow and underflow.
