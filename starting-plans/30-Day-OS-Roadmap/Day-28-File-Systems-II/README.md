## 💬 Interview Q&A
### Q1: How does Bit Vector track free space?
**Ans:** A bitmap where 1 represents a free block and 0 represents an allocated block. Very efficient for small disks.

### Q2: What is a VFS?
**Ans:** A layer above the actual file system that allows standard system calls (like read/write) to work uniformly across different FS types (NTFS, ext4).
