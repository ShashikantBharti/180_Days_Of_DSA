## 💬 Interview Q&A
### Q1: Internal vs External Fragmentation?
**Ans:** Internal: Wasted space within a partition. External: Total free memory is enough for a process, but it's not contiguous.

### Q2: Which allocation strategy is best?
**Ans:** SJF is to CPU as Best-fit is to memory? Actually, First-fit often performs better in practice than Best-fit due to search time.
