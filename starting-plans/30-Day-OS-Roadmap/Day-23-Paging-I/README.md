## 💬 Interview Q&A
### Q1: Explain Paging.
**Ans:** A memory management scheme that eliminates the need for contiguous allocation by dividing physical memory into fixed blocks (frames) and logical memory into pages.

### Q2: What is a Translation Lookaside Buffer (TLB)?
**Ans:** A small, fast-associative hardware cache that stores recent virtual-to-physical address mappings to speed up paging.
