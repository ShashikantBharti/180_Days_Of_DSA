## 💬 Interview Q&A
### Q1: Authentication vs Authorization?
**Ans:** Authentication confirms identity (Username/Password). Authorization determines what an authenticated user can do (Permissions).

### Q2: Difference between Virus and Worm?
**Ans:** A virus needs a host file and human action to spread. A worm is self-replicating and spreads through networks automatically.
