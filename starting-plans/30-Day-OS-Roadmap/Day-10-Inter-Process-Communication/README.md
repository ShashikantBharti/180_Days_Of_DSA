## 💬 Interview Q&A
### Q1: Shared Memory vs Message Passing?
**Ans:** Shared memory is faster because it's direct memory access. Message passing is easier to implement across distributed systems and more secure/synchronized.

### Q2: What is a Pipe in Linux?
**Ans:** A unidirectional communication channel between two related processes.
