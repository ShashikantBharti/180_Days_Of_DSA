## 💬 Interview Q&A
### Q1: What is Kernel Mode?
**Ans:** A privileged mode where the OS has complete access to hardware and all memory. Vital tasks run here to prevent user errors from crashing the system.

### Q2: What is a System Call?
**Ans:** A mechanism that provides an interface between a process and the OS, allowing a user-space application to request services from the kernel.

### Q3: Why do we need two modes of operation?
**Ans:** To protect the system and users from malicious or buggy programs. User programs cannot directly access hardware.

### Q4: Name common system calls.
**Ans:** fork(), exec(), wait(), read(), write(), open(), close().
