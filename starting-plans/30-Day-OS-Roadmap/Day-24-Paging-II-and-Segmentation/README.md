## 💬 Interview Q&A
### Q1: Segmentation vs Paging?
**Ans:** Paging is a hardware technique (fixed blocks). Segmentation is a user's view (variable blocks based on logical segments like code, stack).

### Q2: Why use Multilevel Paging?
**Ans:** To reduce the amount of physical memory used for the page table itself in systems with large address spaces.
