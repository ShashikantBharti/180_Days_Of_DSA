## 💬 Interview Q&A
### Q1: What is Processor Affinity?
**Ans:** The tendency of an OS to keep a process running on the same CPU to keep its cache 'warm'.

### Q2: Asymmetric vs Symmetric Multi-processing?
**Ans:** In Asymmetric, one 'master' processor handles all scheduling. In Symmetric, each processor schedules itself from a common or per-processor queue.
