## 💬 Interview Q&A
### Q1: List 5 critical responsibilities of an OS kernel.
**Ans:** Process management, Memory management, File system management, I/O management, Security/Access control.

### Q2: How does an OS handle a system call?
**Ans:** 1. Trap is triggered. 2. CPU switches to kernel mode. 3. OS consults system call table. 4. ISR executes. 5. Return to user mode.
