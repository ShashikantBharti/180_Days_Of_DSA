## 💬 Interview Q&A
### Q1: What is an Interrupt?
**Ans:** A signal sent to the CPU by hardware or software indicating an event that needs immediate attention.

### Q2: What happens during the boot process?
**Ans:** Power-on self-test (POST) -> BIOS/UEFI loads bootloader -> Bootloader loads Kernel -> OS initializes.

### Q3: Difference between a Trap and an Interrupt?
**Ans:** An interrupt is hardware-generated (asynchronous). A trap is a software-generated interrupt caused by an error or system call (synchronous).
